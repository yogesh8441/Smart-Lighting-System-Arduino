# Smart Lighting System Using Arduino UNO and LDR Sensor

## Overview
This project implements an automatic lighting system using Arduino UNO and an LDR sensor.

## Components Used
- Arduino UNO
- LDR Sensor Module
- LED
- Resistor

## Results
- Dark Condition: Sensor Value ≈ 1015 → LED ON
- Bright Condition: Sensor Value ≈ 8 → LED OFF

## Applications
- Automatic Street Lights
- Smart Home Automation
- Energy Saving Systems
